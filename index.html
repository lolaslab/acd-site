Bringing accessibility support data to developer tools

Browser compatibility data doesn't tell you if a feature works with assistive technology. ACD adds accessibility support data to the tools developers already use, working with Mozilla, BCD, ARIA-AT and Baseline. Support data doesn't tell you whether a feature is accessible, it shows where browsers and screen readers fall short, so you can plan workarounds.

Roadmap

ACD is in early development but here's how we're going to get from tests to developer tools:

  1. Expand test coverage Add browser and screen-reader tests for HTML features to Web Platform Tests and ARIA-AT.
  2. Compute a support status Combine those results into a machine-readable support status for each feature.
  3. Bring it to developer tools Get the data into the tools developers already use, like MDN and Baseline.
